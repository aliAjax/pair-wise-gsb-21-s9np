# hxwl-07 航空维修检查清单

按ATA章节推进维修放行前检查,内置保留故障台账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口:5107

## 保留故障台账

- **机队登记**:每架飞机登记机型、累计飞行小时与循环,到港后可更新飞行数据
- **保留登记**:缺陷按 ATA 章节记录类别(A/B/C/D)、期限(日历天/飞行小时/循环)与 MEL 依据,已飞数据自本机当前累计起算
- **到限停场**:日历天、飞行小时、循环任一期限到限即转停场,放行签署被禁止;航前放行可看到每架飞机最早到限项与剩余可飞数据
- **排故关闭**:登记件号、工作者、复检人与复检结论,复检通过才关闭;不通过保持打开并留痕
- **延长期限**:由值班工程师签署并写明依据,旧期限进入期限沿革仍可查询
- **重开办理**:已关闭项可重新打开,期限自当前飞行数据重新起算
- **按机筛选**:台账支持按飞机、按状态(监控中/临近到限/到限停场/已关闭)筛选,到限项自动置顶

## 分层结构(资料、判定、本机保存分开维护)

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 资料 | `src/data/reference.ts` | MEL 保留类别期限、ATA 章节等基础资料 |
| 判定 | `src/domain/deferral.ts` | 已飞数据、剩余期限、到限判定、放行决策(纯函数) |
| 本机保存 | `src/data/store.ts` | 机队/保留项/放行记录的 localStorage 持久化 |
| 界面 | `src/components/` | 机队放行、保留登记、台账看板 |

## 初始功能

- 领域指标看板(在册飞机/监控中/临近到限/到限停场)
- 机队放行状态卡与放行签署控制
- 保留故障登记表单
- 保留故障台账(筛选、排故、延期、重开、期限沿革)
- 可继续扩展IndexedDB、权限、后端API和复杂图表
