# hxwl-07 航空维修检查清单 · 保留故障台

按 ATA 章节登记保留故障，期限按日历天 / 飞行小时 / 循环控制；任一到限即转停场，不能签放行。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5107

## 保留故障台功能

- **机队台账**：每架飞机登记机型、累计飞行小时与循环；左侧按飞机筛选保留项
- **保留登记**：缺陷按 ATA 章节记录类别（A/B/C/D）、期限单位与期限值，登记时锁定小时/循环基准
- **已飞数据**：登记飞行后，按小时/循环控制的保留项已消耗量自动更新
- **放行判定**：任一保留项到限，该机即转停场，放行判定显示"不能签放行"及阻断原因；临期项提前告警
- **排故关闭**：登记件号、工作者与排故措施后转待复检；复检通过方可关闭，不通过退回排故
- **延期管理**：值班工程师写明依据方可延期，旧期限在"历史与旧期限"中保留可查
- **重新打开**：已关闭项可重开继续办理，原关闭结论作废并留痕
- **操作轨迹**：登记、排故、复检、延期、重开全程留痕

## 分层结构（资料 / 判定 / 本机保存 分开维护）

| 模块 | 职责 |
| --- | --- |
| `src/data/reference.ts` | 资料层：ATA 章节、MEL 类别与默认期限、示例机队与种子台账 |
| `src/domain/deferral.ts` | 判定层：期限计算、到限判定、放行结论、状态流转（纯函数） |
| `src/storage/ledgerStore.ts` | 本机保存层：localStorage 读写，可替换为 IndexedDB 或后端 API |
| `src/App.tsx` | 界面：机队筛选、放行判定、登记与办理表单、台账列表 |
